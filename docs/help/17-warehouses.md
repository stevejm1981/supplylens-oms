# Warehouses

> `/warehouses`

Configurable stock locations: your own unit, a 3PL site, an overflow store. Receiving, despatch, and every stock view run against these.

1. Click `+ New warehouse` and give it a Name and short Code. The **first warehouse you create automatically becomes the default**.
2. Tick **Default warehouse** on whichever site should pre-select everywhere: PO receiving and new sales orders both start on the default (a customer's own default warehouse overrides it on their orders).
3. Read the list: SKUs held, units on hand, stock value at landed cost, and how many sales orders ship from each site.

> **Careful:** Delete guard A warehouse holding stock or carrying sales orders can't be deleted, move the stock story elsewhere first.
